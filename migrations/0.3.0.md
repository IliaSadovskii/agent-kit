# Migrating to 0.3.0 — the kit is Claude Code only

0.3.0 removes Codex support. If your project only ever used Claude Code, the update is transparent
and this note is informational. If you installed the Codex adapter, read on.

## What the updater does for you

`install.sh update` removes every kit-owned file recorded in `kit.lock` that the release no longer
ships — that covers `.agents/skills/*`, `.codex/agents/*`, and `.agent-kit/platforms/*`. A file you
had edited locally is left in place with a warning instead of being deleted.

## What you have to do by hand

The installer deliberately never deletes shared or user-owned files, so these survive the update
and are now dead weight:

```bash
rm -rf .agents .codex        # empty after the update, unless you kept local edits
rm AGENTS.md                 # the Codex bootstrap; delete it or keep your own notes
```

`.codex/hooks.json` is a shared project file — the kit only ever added its `SessionStart` hook to
it. Delete the file, or drop just that hook if you use `.codex/hooks.json` for something else.

If you kept Codex-specific rules in `AGENTS.md`, move anything still relevant into
`.agent-kit/project/instructions.md` (shared) or the override section of `CLAUDE.md`
(Claude-specific) before deleting it.

## The pipeline lost a step

`ship` no longer has a `Plan review` stage, and the `plan-reviewer` subagent is gone — the updater
deletes `.claude/agents/plan-reviewer.md` for you. Design approval, implementation, `tester`,
`reviewer`, and the security pass are unchanged.

If you relied on that stage, the replacement is not another subagent: keep the review in the main
agent loop, where it already has the context. Anthropic's Claude 5 guidance is explicit that
delegating verification to a subagent produces over-verification without improving results.

## Other changes

- `install.sh --providers` is gone. Passing it is now an error; there is one adapter.
- `kit.lock` no longer records a `providers:` key, and `install.sh status` no longer prints one.
- `.agent-kit/platforms/` is gone. Its three Claude-specific rules (branch prefix, the security
  review capability, how to open a PR) moved into `.agent-kit/engine.md`.
- Root `CLAUDE.md` imports two files instead of three; the managed block is rewritten in place by
  the update.

## Verifying

```bash
.agent-kit/scripts/validate.sh
bash install.sh status
```
