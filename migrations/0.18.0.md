# Migrating to 0.18.0

Three command entry points fold into the commands that already covered their ground. Nothing they
did is gone — only where you type it changed.

| Before | Now |
|---|---|
| `/agent-kit:debug [symptom]` | `/agent-kit:fix [symptom]` — a task whose cause is unknown runs the same root-cause discipline before continuing through `fix`'s own steps |
| `/agent-kit:address [pr]` | `/agent-kit:fix --pr <n>` (or paste the PR URL as the task) — same execution contract, different entry point |
| `/agent-kit:screens-riff [focus]` | `/agent-kit:riff [focus]` — a screen theme (an `S<digits>` token, or an explicit mention of screens or the map) routes into the same screen-proposal pass |

If you referenced the old names in your own docs, scripts, or scheduled tasks, find them with:

```bash
grep -rn '/agent-kit:\(debug\|address\|screens-riff\)\b' .
```

Nothing else about these commands changed: `fix`'s and `riff`'s own steps, and the execution
contract of all three folded passes, are what they were.
