# Probe: report what you can see from here

You are the first thing the kit runs in a new session, and the only thing it wants is the
truth about where you landed. Nothing here changes the project. Do not build, do not fix,
do not tidy.

Do exactly this:

1. Say which git branch this working copy has checked out.
2. Find out whether you can write to it — create a file, delete it again.
3. Note anything a longer job would trip over: a dirty tree, a missing tool, a repository
   you were not expecting, a working directory that is not what the input said it was.

Report what you found, not what you assume. If a step failed, the note that says so is
worth more than a guess that reads well.
